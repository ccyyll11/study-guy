# 训练、评分与错题回炉

## 从目标设计题目

先建立知识点和能力矩阵，再出题。A 检查定义、条件和单步方法；B 改变表述、数据或边界，要求辨认方法；C 综合多个有真实联系的知识点，要求解释或迁移。多道机械换数字题不算多个能力目标。

题干提供必要假设、数据、单位与输出要求。若目标本来是识别信息不足，应明确允许“无法确定”并在解析中解释。为学生留下演算、画图或论证空间。

先独立解题再定稿解析。计算可用工具复核，保留过程；证明检查条件和反例；代码题核验输出或给最小可运行验证；阅读与论述题区分事实、解释和立场。

## 参考解析结构

题号 → 核心答案 → 关键步骤 → 为什么用此方法 → 建议得分点 → 典型误区 → 重练动作。简题可以简化，不硬填七个标题。

提示可以分层：提示 1 指出相关概念，提示 2 指出起手式，提示 3 给关键中间步骤。提示和答案集中在解答文件，防止题目页直接泄题。

评分规则服务于自检。真实 rubric 有来源就按来源，没有则写“建议评分”；不虚构教师扣分习惯。多种正确解法应接受；论述题列可接受答案范围。

## 时间预算

默认按每讲 60–90 分钟设计；用户给预算时以用户为准。总时间包括诊断、讲解、独立练习、核对和改错。30 分钟速通保留前置诊断、核心讲解和少量代表题；临考冲刺依据已知范围与真实薄弱点取舍，不承诺押题。

复习计划可采用当天、次日、3 天后、7 天后作默认间隔，但按截止时间、成绩与材料量调整；它是可修改安排，不是适合所有人的科学定律。除非另有明确请求，不创建日历或提醒。

## 用真实作答更新

未作答时掌握度为“未测”。拿到作答后区分：概念不清、方法选择、条件遗漏、推导／计算、表达／单位、时间分配。不要把所有错误归因于粗心，也不要从一次正确直接推断已经熟练。

错题记录建议包含：题号、学生原答、自信度、错误步骤、知识点、错因、修正理由、下一题、复测日期、复测结果。保存用户真实回答；不要替学生编造记录。

回炉流程：用自己的话解释错因 → 重新独立做原题 → 做一道新变式 → 隔一段时间闭卷再测。给明确的进阶条件，例如“能独立解释适用条件并做对一道新变式”；没有结果时只给待执行计划。

诊断偏弱就降低跨度、补前置；基础正确但迁移失败就加辨析和反例；正确且能解释再增加综合题。用户反馈只更新相关知识点和题目，保留已完成记录。
